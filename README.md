# MadarTech Rental Privacy Policy

This repository hosts the privacy policy for MadarTech Rental and OmRents, operated by MadarTech iVMS.

Public page: https://alsawaqi.github.io/madartech-rental-privacy-policy/privacy-policy.html

Effective date: 13 October 2026

Privacy contact: info@madargps.com

## Updating the page

Edit `privacy-policy.html` and keep `index.html` identical to it. Commit and push both files to the publishing branch, `codex/privacy-policy`. GitHub Pages publishes from that branch's root directory.

Keep the public URL stable when updating the policy. Update its effective date when the data practices or policy change.

The application source and signing files are not part of this repository.
